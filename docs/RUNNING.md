# איך מריצים את הקליטה — שלב אחר שלב

מיועד למי שלא הריץ קוד בחייו. כל שלב הוא העתקה והדבקה.

---

## למה זה במחשב שלך ולא אצל Claude

סביבת העבודה של Claude חוסמת קריאות מאומתות לשרתי Anthropic. זו מגבלה של הסביבה,
לא של המפתח שלך. מהמחשב שלך זה יעבוד.

---

## שלב 0 — לפני הכול: מפתח חדש

המפתח שהדבקת בצ'אט **חשוף**. צריך להחליף אותו:

1. היכנסי ל-[console.anthropic.com](https://console.anthropic.com) → **API keys**
2. ליד המפתח הקיים — **Delete**
3. **Create key** → העתיקי את החדש

---

## שלב 1 — Python

בדקי אם הוא כבר מותקן. פתחי **Command Prompt**
(מקש Windows → הקלידי `cmd` → Enter) והדביקי:

```
python --version
```

אם קיבלת מספר כמו `Python 3.11.5` — יש לך, המשיכי לשלב 2.

אם קיבלת שגיאה — הורידי מ-[python.org/downloads](https://www.python.org/downloads/).
**בהתקנה חשוב לסמן את התיבה "Add Python to PATH"** במסך הראשון. בלעדיה שום דבר
לא יעבוד. אחרי ההתקנה סגרי את החלון ופתחי אותו מחדש.

## שלב 2 — הספריות

```
pip install anthropic pdfplumber pypdfium2 pydantic
```

לוקח דקה או שתיים. אם מופיעות שורות אדומות על גרסאות — בדרך כלל זה בסדר,
כל עוד בסוף כתוב `Successfully installed`.

---

## שלב 3 — הקוד

1. היכנסי ל-[github.com/MayaHertzanu-creator/Huris-pilot](https://github.com/MayaHertzanu-creator/Huris-pilot)
2. כפתור ירוק **Code** → **Download ZIP**
3. פרסי את הקובץ
4. גררי את התיקייה שבפנים לכאן, ושני את שמה ל-**huris-agents**

התוצאה צריכה להיראות כך:

```
נבדקים לדוגמא\
├── נבדק א\  ...  נבדק ז\
├── huris-agents\
│   └── agents\
├── הרץ_קליטה.py
└── .env
```

---

## שלב 4 — המפתח

יש כבר קובץ `.env` בתיקייה. פתחי אותו ב-Notepad והחליפי את המפתח הישן בחדש.
שורה אחת בלבד:

```
ANTHROPIC_API_KEY=sk-ant-api03-המפתח-החדש
```

אם הקובץ לא נראה: **View → Show → Hidden items**.

---

## שלב 5 — הרצה

ב-Command Prompt:

```
cd "%USERPROFILE%\Desktop\מכון\נבדקים לדוגמא"
python הרץ_קליטה.py
```

תראי התקדמות בזמן אמת:

```
── נבדק א
   ✓ file_1  [screening_test]  קריאוּת: high
   ✗ file_3  [other]           קריאוּת: low
```

**זמן:** 10–20 דקות ל-85 עמודים. **עלות:** 2–3 דולר.

---

## התוצאות

בתיקייה חדשה בשם `_תוצאות`:

| קובץ | מה יש בו |
|---|---|
| `נבדק X — תמלול.md` | הטקסט המלא. **זה מה שסוכן ג' יקבל** |
| `נבדק X — תגיות.md` | פלט הצינור, לאימות בלבד |

**התמלול הוא מה שחשוב.** עברי עליו מול הסריקה המקורית ובדקי:

- האם `[לא קריא]` מופיע במקומות שבאמת לא קריאים?
- האם משהו **הומצא** — טקסט שנראה סביר אבל לא כתוב במקור?
- האם השוליים החתוכים סומנו ולא הושלמו?

השאלה השנייה היא הקריטית. פער מסומן הוא תקין; המצאה היא כשל.

## אם משהו נשבר

| מה שרואים | מה לעשות |
|---|---|
| `'python' is not recognized` | Python לא ב-PATH. התקיני מחדש עם התיבה מסומנת |
| `לא נמצא מפתח` | ה-`.env` לא במקום או שהשם שלו `.env.txt` |
| `לא נמצא קוד הפרויקט` | תיקיית `huris-agents` לא במקום או בשם אחר |
| `authentication_error` | המפתח שגוי, או שאין קרדיט בחשבון |
| `rate_limit` | הריצי שוב בעוד כמה דקות; מה שנקלט נשמר |

בכל מקרה אחר — העתיקי את הודעת השגיאה לצ'אט.
